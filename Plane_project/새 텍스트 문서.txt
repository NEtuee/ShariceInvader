공간 분할

|                         |


위같은 공간이 있으면 저걸 일정 조각 수 대로 나눔

|   |   |   |   |   |   |   |

각 공간은 분할될 때 맨 왼쪽부터 0 ~ n 의 고유 번호를 가짐. 공간은 항상 왼쪽 아래 꼭지점부터 시작함

모든 게임 오브젝트는 각 공간에 속해야 함. 오브젝트가 다른 공간으로 이동할 경우 소속도 바뀜

이 때 플레이어가 속해 있는 공간을 중심 공간이라고 함.

| 1 |   |   | 플 |   |   | 2 |

위와 같은 상황에서 플레이어가 인접한 왼쪽 공간으로 이동할 경우

| 1 |   | 플 |   |   |   | 2 |

이동한 반대 방향에 가장 멀리 떨어진 공간을 이동한 방향으로 가장 멀리 떨어진 공간 앞에 붙임

| 2 | 1 |   | 플 |   |   |   |

공간이 이동할 때 그 공간에 속한 모든 오브젝트도 같이 이동함


공간마다 순서대로 고유한 번호가 있음 -> 실제 좌표와 다른 공간 안의 가상의 좌표를 쉽게 구할 수 있음

예: 실제 좌표는 100에 있는 플레이어의 공간 좌표를 구할 경우 
현재 공간의 고유 번호 * 공간의 길이 + (플레이어 실제 좌표 - 공간의 실제 좌표(왼쪽 아래 꼭지점))


충돌 처리는 같은 공간에 속한 오브젝트끼리만 실행함

즉 현재 적 1, 2와 플레이어는 충돌 처리를 하고있지 않음
